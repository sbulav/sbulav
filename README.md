# Hi, I'm Sergei Bulavintsev 👋

I lead a team of DevOps engineers and stay hands-on, writing code and building Kubernetes operators for infrastructure running **hundreds of thousands of pods**.

My focus is designing production infrastructure and staying involved in the technical decisions that shape it. I also build Neovim plugins and share what I learn on [my blog](https://sbulav.github.io/).

## Things I've built

- **[Calico Policy Visualiser](https://github.com/sbulav/calico-policy-visualiser)** — Explore Kubernetes and Calico network policies through interactive diagrams and plain-English explanations, right in your browser.
- **[jira-oil.nvim](https://github.com/sbulav/jira-oil.nvim)** — Edit Jira backlogs and sprints like a regular Neovim buffer.
- **[nredir.nvim](https://github.com/sbulav/nredir.nvim)** — Bring Vim and shell command output into a Neovim scratch buffer.
